## MyPoint
```java
public abstract class MyPoint {
    private int x;
    private int y;

    public MyPoint(int x, int y) {
        this.x = x;
        this.y = y;
    }

    public abstract void output();
    public abstract void calc();

    public int getX() {
        return x;
    }

    public int getY() {
        return y;
    }
}
```
## MyCircle
```java
public class MyCircle extends MyPoint {
    private static final float PERIMETER = 3.14f;

    private int radius;
    private float area;

    public MyCircle(int x, int y, int radius) {
        super(x, y);
        this.radius = radius;
    }

    @Override
    public void output() {
        String output = "x=" + getX() + ", y=" + getY() + ", r=" + getRadius() + ", area=" + getArea();
        System.out.println(output);
    }

    @Override
    public void calc() {
        this.area = radius * radius * PERIMETER;
    }

    public int getRadius() {
        return radius;
    }

    public float getArea() {
        return area;
    }
}
```

* `extends`: 상속받을때 사용
  * 상속 받으면 MyPoint의 멤버 변수나 함수 사용 가능
  * 자세한건 거기 선생님한테 물어보셈
* `private static final` : 보통 상수 쓸때 사용
    * 자세한건 나중에 알아도됨 걍 함수에서 선언해서 써도 되는데 메모리때매 이렇게 보통 씀
    * 결론은 원주율값 선언해놓은거고, 저렇게 선언한 이유는 지금은 몰라도됨
* `get***`: getter 멤버함수 값 가져올때 사용
* `calc` : area 구하는 공식

## MyTriangle
```java
public class MyTriangle extends MyPoint {
    private static final double HALF = 0.5d;
    private int width;
    private int height;
    private double area;

    public MyTriangle(int x, int y, int width, int height) {
        super(x, y);
        this.width = width;
        this.height = height;
    }

    @Override
    public void output() {
        String output = "x=" + getX() + ", y=" + getY() + ", w=" + getWidth() + ", h=" + getHeight() + ", area=" + getArea();
        System.out.println(output);
    }

    @Override
    public void calc() {
        this.area = getWidth() * getHeight() * HALF;
    }

    public int getWidth() {
        return width;
    }

    public int getHeight() {
        return height;
    }

    public double getArea() {
        return area;
    }
}
```
* `public MyTriangle(int x, int y, int width, int height)`: 이게 생성자
  * x,y, width, height 를 받아서 myTriangle 객체를 만들겠다는 거임
  * `super(x,y)` 이부분은 상속 받은 부모객체의 생성자임 MyPoint에 있는 생성자 호출한거


## Main
```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        MyPoint[] myPoints = new MyPoint[50];
        Scanner scanner = new Scanner(System.in);

        for (int i = 0; i < myPoints.length; i++) {
            System.out.print("1) circle 2)triangle 3)all print 4)exit");
            int menu = scanner.nextInt();
            switch (menu) {
                case 1:
                    addCircle(myPoints, scanner, i);
                    System.out.println("finish");
                    break;
                case 2:
                    addTriangle(myPoints, scanner, i);
                    System.out.println("finish");
                    break;
                case 3:
                    printAll(myPoints);
                    break;
                case 4:
                    System.out.println("exit!");
                    return;
                default:
                    System.out.println("wrong input!");
                    return;

            }
        }
    }

    /**
     * 들어가 있는 거 전체 출력
     * @param myPoints
     */
    private static void printAll(MyPoint[] myPoints) {
        for (MyPoint myPoint : myPoints) {
            if (myPoint != null) {
                myPoint.output();
            }
        }
    }

    /**
     * 삼각형 생성 하고 배열에 추가
     * @param myPoints
     * @param scanner
     * @param i
     */
    private static void addTriangle(MyPoint[] myPoints, Scanner scanner, int i) {
        int x = scanX(scanner);
        int y = scanY(scanner);
        int width = scanWidth(scanner);
        int height = scanHeight(scanner);
        MyTriangle myTriangle = new MyTriangle(x, y, width, height);
        myTriangle.calc();
        myPoints[i] = myTriangle;
    }

    /**
     * 원 생성 추가
     * @param myPoints
     * @param scanner
     * @param index
     */
    private static void addCircle(MyPoint[] myPoints, Scanner scanner, int index) {
        int x = scanX(scanner);
        int y = scanY(scanner);
        int radius = scanRadius(scanner);
        MyCircle myCircle = new MyCircle(x, y, radius);
        myCircle.calc();
        myPoints[index] = myCircle;
    }

    private static int scanX(Scanner scanner) {
        System.out.println("x:");
        return scanner.nextInt();
    }

    private static int scanY(Scanner scanner) {
        System.out.println("y:");
        return scanner.nextInt();
    }

    private static int scanRadius(Scanner scanner) {
        System.out.println("r:");
        return scanner.nextInt();
    }

    private static int scanWidth(Scanner scanner) {
        System.out.println("w:");
        return scanner.nextInt();
    }

    private static int scanHeight(Scanner scanner) {
        System.out.println("h:");
        return scanner.nextInt();
    }
}
```
